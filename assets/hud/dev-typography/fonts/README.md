# Dev typography fonts (Live Typography Playground)

Drop candidate `.ttf` / `.otf` files here, using the filenames listed in `../fonts.json`, or add your own entry there. Then press `r` in the running ExperienceRuntime. You don't need to recompile.

Only add fonts whose license allows it. The suggested candidates (Rajdhani, Oxanium, Barlow Condensed, IBM Plex Mono, Share Tech Mono) are all SIL Open Font License 1.1 families from Google Fonts. Keep each family's `OFL.txt` next to its files.

DEV ONLY. These files are not part of any HUD skin and are not required by the runtime.
